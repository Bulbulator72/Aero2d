# NLR 7301 с щелевым закрылком (δf = 20°)

Эталонный случай для проверки CFD на механизации: ERCOFTAC UFR 3-01 / EUROVAL / ECARP
(https://kbwiki.ercoftac.org/w/index.php/UFR_3-01_Test_Case).

## Геометрия
- `nlr7301_gap26.dat` — щель 2,6 % c, перекрытие 5,3 % c;
- `nlr7301_gap13.dat` — щель 1,3 % c, перекрытие 5,3 % c.

Контуры взяты со стенок многоблочной сетки SAAB, которую ERCOFTAC даёт для этого случая
(`UFR3-01_nlr7301grid.zip`, файлы `nlrgap26.dat`, `nlrgap13.dat`): основной элемент — 457 точек
(задняя кромка «козырька» x = 0,9436), закрылок — 249 точек. Формат — многоэлементный файл aero2d
(блоки через «999 999», каждый от задней кромки по верхней стороне). Координаты — в долях хорды
крыла с убранным закрылком: **опорная хорда c = 1** (по ней Re и коэффициенты в эксперименте).

## Условия продувки (NLR, 1979 и 1989)
M = 0,185, Re = 2,51·10⁶ (по хорде крыла, c = 0,57 м), δf = 20°.

## Данные эксперимента (ERCOFTAC UFR 3-01, табл. 3)
| конфигурация | α | Cl | Cd |
|---|---|---|---|
| щель 2,6 % | 13,1° | 3,141 | 0,0445 |
| щель 1,3 % | 6,0°  | 2,416 | 0,0229 |

Переход (сублимация), x/c:
| | щель 2,6 %, α 13,1° | щель 1,3 %, α 6° |
|---|---|---|
| крыло, верх | 0,024–0,035 | 0,027–0,040 |
| крыло, низ | 0,710–0,740 | 0,635–0,675 |
| закрылок, верх | 1,065–1,080 | 1,063–1,081 |
Нижняя сторона закрылка — ламинарная до кромки.

Поправки на стенки трубы уже внесены в данные (блокировка, Cd из распределения давления,
ΔCl = −0,0148 (Cl + 2Cm)). Распределения Cp, профили скорости в слое и следе — в отчёте
van den Berg, NLR TR 79009 U (1979) и в трудах EUROVAL (Notes on Numerical Fluid Mechanics, т. 42, 1992).

## Как сравнивать
Для RANS обычно считают полностью турбулентно; с переходом — задать точки перехода по таблице.
Точка α = 13,1° при щели 2,6 % — близко к Cl_max: строгая проверка модели турбулентности на больших углах.
