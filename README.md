# aero2d — аэродинамика двумерных профилей

Эталонные тесты, панельный метод, **вязко-невязкий метод с числом Рейнольдса**
(панели + интегральный пограничный слой, как XFOIL) и пакетный решатель
уравнений Эйлера на JAX (CPU/GPU, FP32/FP64). Окно программы для расчётов.

## Состав

| Модуль | Что делает | Состояние |
|---|---|---|
| `aero2d/geometry.py` | NACA 4, модифицированные NACA 00xx-IT и серия 16 (симметричные для оперения, ординаты совпадают с таблицами до 1·10⁻⁴), набор симметричных профилей 6-й серии (`aero2d/data/airfoils`, база UIUC), NACA 4, CST (Кульфан), профили Кармана–Треффца/Жуковского с **точным** решением, чтение файлов Selig | готово |
| `aero2d/panel.py` | Панельный метод в формулировке через функцию тока (как XFOIL): линейная завихренность, условие Кутта, экстраполяция на острой кромке; поправка Кармана–Цяня | готово, **2-й порядок**, проверен по точным решениям |
| `aero2d/grid.py` | O-сетка: маршевый рост слоёв по сглаженным нормалям, геометрическое нарастание шага | готово (для Эйлера) |
| `aero2d/euler.py` | Уравнения Эйлера: конечные объёмы, HLLC, MUSCL + ван Албада, характеристическое условие на внешней границе с поправкой на вихрь; явная схема RK4 + сглаживание невязки | готово; явная схема — запасной вариант |
| `aero2d/implicit.py` | **Основной решатель**: псевдонестационарный Ньютон–Крылов (GMRES), точный якобиан через `jax.jvp`, предобусловливатель — блочная прогонка вдоль нормали к стенке; пакет случаев через `jax.vmap` | готово |
| `aero2d/viscous.py`, `aero2d/blclosure.py`, `aero2d/sources.py` | **Вязкий метод**: интегральный пограничный слой (импульс, кинетическая энергия, eᴺ-переход, уравнение запаздывания Cτ), след, строгая связь с панельным методом через массовый дефект; глобальный Ньютон с якобианом комплексным шагом; продолжение по α и по Re; сжимаемость до M ≈ 0,7 | готово, сверено с XFOIL 6.99 |
| `aero2d/multi.py` | Многоэлементный панельный метод (невязкий); генератор механизации `highlift()`: однощелевой, Фаулера, двухщелевой закрылок, предкрылок — хорда, угол, зазор, перекрытие каждого элемента; чтение многоэлементных файлов | готово |
| `aero2d/mviscous.py` | **Вязкий расчёт механизации**: у каждого элемента свой пограничный слой и след по линии тока, источники вытеснения на всех телах и следах, один Ньютон на всю систему; продолжение по Re для первой точки | готово, сверено с NASA CR-2443 (до Cl_max) |
| `aero2d/rans.py`, `aero2d/rans_mesh.py`, `aero2d/bilu.py`, `aero2d/krylov.py` | **RANS**: уравнения Навье–Стокса, осреднённые по Рейнольдсу, + модель Спаларта–Аллмараса (SA-neg) на неструктурированной гибридной сетке gmsh (слой четырёхугольников у стенок с y⁺ ≈ 1, треугольники снаружи, сгущение в щелях и по следам; сетка не зависит от угла атаки); конечные объёмы, LM-Roe, МНК-градиенты + ограничитель Венкатакришнана у задних кромок; псевдонестационарный Ньютон–Крылов (GMRES, точный якобиан-на-вектор через `jax.jvp`, предобусловливатель — блочный ILU(k), по умолчанию k = 3, или точное LU в порядке вложенных сечений); скомпилированные функции кэшируются на диске; **нестационарный расчёт** (`solve_unsteady`: BDF2, двойной шаг по времени); одно- и многоэлементные профили | готово, сверено с NASA TMR (NACA 0012) и CR-2443 (механизация) |
| `aero2d/animate.py` | **Анимация поля течения по времени (GIF)** по кадрам нестационарного RANS: завихренность, скорость, Cp, M, ν̃; внизу — Cl(t) | готово |
| `aero2d/controls.py` | Рули и элероны: отклонение задней части вокруг оси одним контуром (как FLAP в XFOIL), шарнирный момент Ch по распределению давления + осевая компенсация (модель равномерного давления в нише) | невязкий Ch проверен по теории Глауэрта (3–6 %) и совпадает с XFOIL; вязкий — см. ограничения |
| `aero2d/parallel.py` | Параллельный расчёт поляр на ядрах процессора: поляра делится на куски по α (внутри — продолжение по α), несколько Re — одновременно; число ядер определяется на том ПК, где запущена программа | готово |
| `aero2d/field.py` | Поле течения: Cp и скорость в пространстве, линии тока, граница вытеснения (контур + δ*) и след; для вязкого расчёта учитываются источники вытеснения | готово |
| `aero2d/core.py`, `aero2d/gui.py` | Окно программы (`python -m aero2d.gui`): профиль NACA или из файла; вязкий метод (Re, Ñкрит, принудительный переход), панели или Эйлер; RANS для механизации у Cl_max (вкладки «Сетка» — параметры и просмотр сетки, «Невязки» — ход невязок по уравнениям и критерий перехода к следующему углу; углы поляры — параллельно в нескольких процессах); графики Cl/Cd/Cm/Cp, пограничный слой (трение, H, δ*, Ñ), поле течения, таблица, экспорт CSV/PNG | готово |
| `tests/` | pytest: точные решения, консервативность, сходимость, эталоны XFOIL | |
| `benchmarks/` | сверка с XFOIL (`viscous_vs_xfoil.py`), с продувками UIUC (`uiuc_dataset.py`, `uiuc_sweep.py`, `uiuc_summary.py`, `vs_experiment.py`) и NASA LTPT (`vs_ltpt.py`); тест пропускной способности GPU | |
| `benchmarks/data/` | атлас UIUC Low-Speed Airfoil Tests (тома 1–6: 70 «чистых» профилей с координатами моделей, 354 поляры; GPL) и данные NASA LTPT по E387 | |

## Установка

На Windows рекомендуется WSL2 (Ubuntu): JAX с CUDA работает только под Linux.

```bash
pip install -e ".[test,rans]"     # CPU (+ gmsh для RANS)
pip install -U "jax[cuda12]"      # GPU (RTX 3080 Ti), в WSL2 или Linux
pytest -q
```

## Окно программы

`python -m aero2d.gui` (в офлайн-комплекте — `7_aero2d_WINDOW.bat`). Слева сверху вниз: профиль →
метод (список; по умолчанию вязкий, как XFOIL) → условия расчёта → кнопка «Рассчитать».
Видны только параметры и вкладки выбранного метода (у RANS — свои параметры и вкладки
«Сетка», «Невязки»); у каждого поля есть подсказка при наведении. Ctrl+Enter — расчёт,
Esc — остановить. В «Таблице» строки сгруппированы по расчётам, ненадёжные точки — красным.
Ошибки показываются коротким сообщением; техническая трасса — по кнопке «Подробнее».
Неверное значение в поле: сообщение называет поле и допустимый диапазон, поле подсвечивается
и получает курсор. «Вид» → крупнее/мельче шрифт (Ctrl+плюс / Ctrl+минус / Ctrl+0): вместе со
шрифтом увеличиваются панель, столбцы таблицы и подписи графиков; размер запоминается
(`~/.aero2d_gui.json`).

## Быстрый старт

```python
from aero2d.geometry import naca4
from aero2d.panel import PanelSolver
from aero2d.grid import ogrid
from aero2d.euler import EulerSolver
from aero2d.implicit import ImplicitEuler

af = naca4("2412", 121)

# панели: поляра за миллисекунды
ps = PanelSolver(af)
print(ps.solve(4.0, mach=0.5).cl)

# вязкий метод: Re, переход, сопротивление
from aero2d.viscous import ViscousSolver
vs = ViscousSolver(af, re=1e6, ncrit=9)
for r in vs.polar([0, 2, 4, 6]):
    print(r.alpha, r.cl, r.cd, r.xtr_u, r.xtr_l, r.converged)

# Эйлер: весь пакет (M, α) решается одновременно
g = ogrid(af, nj=65)
solver = ImplicitEuler(EulerSolver(g))          # dtype=jnp.float32 по умолчанию
r = solver.solve(machs=[0.5, 0.7, 0.8], alphas=[2, 2, 1.25], n_iter=100)
print(r.cl, r.cd, r.cm, r.converged)

# RANS (SA) для механизации: сетка gmsh строится сама, углы — продолжением
from aero2d.multi import highlift
from aero2d.rans import rans_polar
els = highlift(naca4("2412", 161), flap=dict(type="fowler", chord=0.30, deflection=30, overlap=0.02))
res, mesh = rans_polar(els, [0, 5, 10, 12], re=2e6, mach=0.15, verbose=1, workers=3,
                       conv=Convergence(orders=4.5, hold=20))   # from aero2d.rans import Convergence
# сетка с параметрами: mesh_for(els, 5, 2e6, opts=MeshOptions(yplus=1, n_surface=200))
print([(r.alpha, r.cl, r.cd, r.converged) for r in res])

# по времени (BDF2): резкий поворот потока 5° → 12° и GIF завихренности
from aero2d.rans import RansSolver
from aero2d.animate import make_gif
s = RansSolver(mesh, 0.15, 2e6)
Q0 = s._rotate_state(res[1].state, 12 - 5, inner=0.0, outer=0.02)
run = s.solve_unsteady(12.0, Q0, t_end=3.0, steps_per_chord=40, frame_every=2)
make_gif(mesh, els, run, "flap.gif", quantity="vorticity")
```

## Проверено

* **Вязкий метод против XFOIL 6.99** (тот же контур, Ñкрит = 9; подробно —
  `benchmarks/viscous_vs_xfoil.py`):
  * Re = 10⁶…10⁷, до α ≈ 8–10°: Cd — в пределах 1–3 % в большинстве точек
    (отдельные точки до 8–11 %), переход — в пределах 0,01 хорды, Cl — в
    пределах 1–5 %, в отдельных точках до 10–14 % выше XFOIL (NACA 4415,
    Re = 10⁶–10⁷; 0012 при Re = 10⁷). Матрица связи совпадает с XFOIL
    (при подстановке массового дефекта XFOIL получаются его же Ue и Cl);
    расхождение — в решении пограничного слоя у задней кромки;
  * у максимума Cl (0012, Re = 10⁶, α ≥ 10°) Cl ниже XFOIL на 10–20 % —
    срыв наступает раньше;
  * Re = 10⁵: 2412 и 4415 — Cd в пределах 1–6 % почти везде; у 0012 при
    α ≠ 0 Cl на 20–30 % выше, Cd на 15–20 % выше XFOIL (ламинарный пузырь
    описывается иначе) — при Re ≲ 10⁵ результаты пока оценочные;
  * время: 2–5 с на точку при продолжении по α, 10–20 с на первую точку
    (маршевое приближение); при малых Re и трудных точках — дольше.

* **Против продувок — массово, атлас UIUC** (тома 1–3, координаты моделей «как
  испытано», Re ≈ 10⁵, 2·10⁵, 3·10⁵, углы от −2° до (α при Cl_max − 1°),
  каждая вторая точка; `benchmarks/uiuc_sweep.py`, сводка —
  `benchmarks/uiuc_summary.py`; результаты — `benchmarks/uiuc_final.jsonl`).
  Итог по 67 профилям, 182 полярам, 577 точкам (Ñкрит = 9):

  | Re | сошлось «как испытано» | сошлось со сглаживанием* | ΔCl ср. | \|ΔCl\| ср. | ΔCd/Cd медиана | \|ΔCd/Cd\| медиана |
  |---|---|---|---|---|---|---|
  | 10⁵ | 75 % | 87 % | +0,065 | 0,083 | −4,5 % | 7,9 % |
  | 2·10⁵ | 87 % | 94 % | +0,065 | 0,071 | −6,1 % | 7,0 % |
  | 3·10⁵ | 86 % | 95 % | +0,055 | 0,061 | −6,0 % | 7,1 % |
  | всего | 83 % | 92 % | +0,061 | 0,071 | −5,8 % | 7,2 % |

  \* для 29 поляр, где не сошлась половина точек, контур сглажен
  (`smooth_airfoil`, `uiuc_retry_smooth.jsonl`); почти все такие провалы —
  шум измеренных координат у передней кромки. Остались несходящимися в
  основном очень тонкие профили (Goe 417a, SA7035, LD-79) при Re = 10⁵.
  Отклонения — по сошедшимся точкам.
  Вывод: Cd — медианная ошибка ≈ 7 % (сдвиг −5…−6 %, т. е. немного ниже
  эксперимента), Cl систематически выше на ≈ 0,06. XFOIL в том же прогоне
  (каждая точка — отдельный запуск, без продолжения по α) даёт такие же
  отклонения (Cd 7,5 %, Cl +0,05), но сходится реже (около 50 %).
  Разложение отклонения Cl по E387: наклон Cl(α) в UIUC на 6–8 % меньше, чем
  в малотурбулентной трубе NASA LTPT, а расчётный наклон совпадает с LTPT.
  Значит, часть расхождения с UIUC — особенность установки, а не модели.
  Относительно LTPT остаётся сдвиг Cl ≈ +0,04 (≈ 0,4° по углу) — это
  известное свойство метода (как у XFOIL): вязкое «раскамберивание» у задней
  кромки недооценивается.

* **E387 против NASA LTPT** (McGhee и др., NASA TM-4062, 1988; таблица —
  `benchmarks/vs_ltpt_E387.txt`): при Re = 2·10⁵ и Ñкрит = 11 Cd в пределах
  ±5 % при α = 0…6°, при Ñкрит = 9 — на 5–11 % ниже; при Re = 3·10⁵ —
  на 5–9 % ниже при обоих Ñкрит; Cl выше на 0,03–0,05 до α = 6°, при 8°
  совпадает. **Рекомендация: для малотурбулентных труб и полёта в спокойной
  атмосфере Ñкрит = 10–11, для обычных труб — 9.** Калибровка на подвыборке
  UIUC (16 профилей): Ñкрит = 11 уменьшает медианную ошибку Cd с 7 % до 5 %
  (сдвиг с −5 % до +1 %); Ñкрит = 7 ухудшает (−8 %); на Cl Ñкрит почти не
  влияет.

* **E387 по углам (UIUC, Re 6·10⁴…4,6·10⁵; `benchmarks/vs_experiment.py`,
  `benchmarks/vs_experiment_E387.txt`)**: при Re = 6·10⁴ скачок Cl из-за
  пузыря (гистерезис) не воспроизводит ни aero2d, ни XFOIL. При отрицательных
  α (пузырь у носка на нижней поверхности) aero2d сходится до −4…−6° при
  Re = 1–2·10⁵; при Re = 3·10⁵ ниже −4° — нет (XFOIL там тоже не сходится).

* **Рули против продувок NACA** (NACA 0009, руль 0,30c, щель герметична; Ames,
  ARR L-301, 1941; `benchmarks/vs_naca_flap.py`, таблица — `vs_naca_flap.txt`).
  Производные на градус около α = δ = 0, Re = 1,43·10⁶ (турбулентная труба):

  | | cl_α | τ = cl_δ/cl_α | ch_α | ch_δ |
  |---|---|---|---|---|
  | опыт, простой руль | 0,094 | 0,57 | −0,0068 | −0,0120 |
  | aero2d невязкий | 0,118 | 0,67 | −0,0099 | −0,0158 |
  | aero2d вязкий, Ñкрит 2–9 | 0,106–0,114 | 0,66–0,68 | −0,0050…−0,0082 | −0,0125…−0,0145 |
  | опыт, компенсация 0,20c_р, тупой носок | 0,094 | 0,57 | −0,0060 | −0,0088 |
  | aero2d вязкий, Ñкрит 2–9 | 0,106–0,114 | 0,66–0,68 | −0,0042…−0,0073 | −0,0102…−0,0120 |

  Вязкий ch_δ — в пределах 5–20 % от опыта для простого руля, но эффект
  компенсации занижен (опыт −27 %, расчёт −17…−19 %); ch_α сильно зависит от
  Ñкрит (переход у задней кромки). Невязкий расчёт завышает |ch| на 30–45 %.
  Ch в опыте не исправлены на влияние стенок трубы, cl — исправлены.

* **Механизация, вязкий расчёт** — GA(W)-1 + закрылок Фаулера 29 % (NASA CR-2443,
  Wentz & Seetharam 1974; Re 2,2·10⁶, M 0,21, переход на 5 %; геометрия и положения
  оси закрылка — из таблиц отчёта, Cl — оцифровка рис. 7, ±0,02):

  | δf | α, ° | Cl опыт | Cl aero2d | Cl невязкий |
|---|---|---|---|---|
  | 10° | −2,3 / 2,6 / 5,0 | 0,81 / 1,51 / 1,84 | 0,81 / 1,48 / 1,81 | 0,91 / 1,62 / 1,98 |
  | 20° | −2,3 / 2,6 / 5,1 | 1,42 / 2,15 / 2,46 | 1,45 / 2,12 / 2,45 | 1,67 / 2,39 / 2,76 |
  | 30° | −2,5 / 2,4 / 5,0 | 2,05 / 2,73 / 3,02 | 1,98 / 2,63 / 2,96 | 2,42 / 3,15 / 3,52 |

  По 12 точкам до Cl_max: ΔCl = −0,05 в среднем, |ΔCl| = 0,05 (невязкий расчёт
  завышает на 0,1–0,5). У Cl_max (α = 10°): δf = 10° — +0,01, 20° — −0,09,
  30° — −0,37. δf = 40° теперь сходится (продолжение по углу закрылка, 4 из 5
  точек), но Cl занижен на 0,22–0,40: расчёт даёт отрыв на закрылке с ~40 % его
  хорды, а в опыте (рис. 39 отчёта) закрылок обтекается безотрывно. Это не
  ошибка сходимости: тот же закрылок отдельно при таком же пике разрежения
  XFOIL 6.99 и aero2d считают одинаково отрывным (Cl 1,48 / 1,48 при α = 8°),
  т. е. так ведут себя интегральные замыкания XFOIL/MSES для сильно
  нагруженного закрылка.
  Слияние следа со слоем закрылка (`confluent=True`, экспериментально):
  след основного элемента вливается в слой закрылка там, где их толщины
  перекрываются (сохраняются дефициты импульса и массы, сток в конце следа).
  На этих данных точность ухудшается (ΔCl ср. −0,11 вместо −0,07 при
  δf = 10–30°; `vs_gaw1_fowler_confluent.txt`), поэтому по умолчанию выключено. `benchmarks/vs_gaw1_fowler.py`, данные — `benchmarks/gaw1_fowler.py`.
  Другие открытые наборы для следующих сверок: NASA CR-166018 (тот же профиль,
  закрылок 30°/40° с заданными щелью и перекрытием, предкрылок; Cp и Cl),
  NASA TM-100046 (NACA 4412 + закрылок 4415, Re 1,8·10⁶).
* **RANS (SA)** — `benchmarks/rans_check.py` (результат `rans_check.txt`, `rans_check.png`):
  - NACA 0012, M 0,15, Re 6·10⁶, сетка 14 тыс. ячеек — эталоны NASA Turbulence
    Modeling Resource (CFL3D / FUN3D на сетках до 7·10⁶ ячеек):

    | α | Cl aero2d | Cl CFL3D / FUN3D | Cd aero2d | Cd CFL3D / FUN3D |
    |---|---|---|---|---|
    | 0° | 0,000 | 0 | 0,00815 | 0,00819 / 0,00812 |
    | 10° | 1,085 | 1,091 / 1,098 | 0,01257 | 0,01231 / 0,01242 |
    | 15° | 1,543 | 1,546 (CFL3D) | 0,0236 | 0,0212 (CFL3D) |

    Cl — в пределах 0,6 %, Cd при α ≤ 10° — 0,5–2 %; при 15° Cd выше на 11 %
    (сопротивление давления на грубой сетке). 110–175 итераций Ньютона на угол.
    SA-RC (`turb_model="sa-rc"`, поправка Спаларта–Шура на вращение и кривизну):
    α = 0° — Cd на 2,7 % ниже SA, α = 10° — Cl 1,0865, Cd 0,01207 (−4 % к SA); эталон
    TMR для SA-RC (CFL3D / FUN3D / NTS): Cd 0,00793 / 0,00790 / 0,00792 и
    Cl 1,0947 / 1,1020 / 1,0933, Cd 0,01179 / 0,01191 / 0,01193 — то же снижение на 3–4 %.
  - GA(W)-1 + закрылок Фаулера 29 % (CR-2443, Re 2,2·10⁶, M 0,21), сетка 39 тыс.
    ячеек, полностью турбулентный слой:

    | δf | α, ° | Cl опыт | Cl RANS | Cl вязко-невязкий |
    |---|---|---|---|---|
    | 30° | 0 / 5 / 10 / 12 / 14 | 2,43 / 3,02 / 3,38 / — / — | 2,40 / 3,02 / 3,41 / 3,40 / 3,03* | 2,31 / 2,97 / 3,01 / — / — |

    Вязко-невязкий метод — интерполяция `vs_gaw1_fowler.txt` на те же α.

    При δf = 30° RANS совпадает с опытом в пределах 0,03 по всей кривой, включая
    α = 10° (вязко-невязкий: −0,37). Cl_max ≈ 3,41 при α ≈ 10–11°; при α = 12°
    падает Cl закрылка (отрыв на закрылке), при α = 14° отрывается основной
    элемент. При δf = 40° согласие хуже: при α = 0 RANS занижает Cl на 0,27
    (закрылок частично оторван — Cl закрылка почти как при 30°), а при α = 10°
    завышает на 0,23 (в опыте рост Cl к 10° замедляется, в расчёте — нет);
    Cl_max по расчёту 3,74 при α ≈ 10°, по аннотации отчёта наибольший
    достигнутый Cl_max — 3,8. Оба метода (вязко-невязкий и RANS) недооценивают
    закрылок при 40° и малых α — вероятно, сказывается неточность восстановленного
    положения закрылка (щель/перекрытие при 40° взяты по графику оси поворота) или
    полностью турбулентный слой на закрылке. Опытные точки оцифрованы до α = 10°.
    Время на 2 ядрах — 50–100 мин на угол (на многоядерном ПК должно быть заметно меньше).
* **Панельный метод**: ошибка Cl относительно точного решения 0,02 % при 160 панелях,
  второй порядок сходимости (в 4 раза при удвоении), включая профили с «клювом».
  Первоначальная формулировка через скорости давала только первый порядок
  (0,6 %) — заменена.
* **Эйлер** (грубая сетка 128×49): при M = 0,5, α = 2° Cl = 0,2816 — между
  поправками Прандтля–Глауэрта (0,279) и Кармана–Цяня (0,292), Cd ≈ 0;
  NACA 0012 при M = 0,8, α = 1,25° — Cl = 0,349, Cd = 0,0220
  (эталон Cl = 0,351, Cd = 0,0227); M = 0,85, α = 1° — Cl ≈ 0,34, Cd ≈ 0,056.
* **Неявный решатель**: дозвук и M = 0,8 сходятся за 20–50 итераций Ньютона;
  при M = 0,85 за 80 итераций невязка падает на 4 порядка (силы уже стабильны).
* **FP32 и FP64** дают одинаковые Cl, Cd, Cm (расхождение ≤ 2·10⁻⁴). Разница —
  в «полу» невязки: FP32 останавливается на ~10⁻⁶ от начальной, FP64 идёт до
  10⁻¹³. Для сил этого достаточно; для RANS при y⁺ ~ 1 и Re до 10⁸ нужно
  проверить отдельно.

Подробные цифры — `benchmarks/results.md` (после запуска `run_benchmarks.py`).

## Известные ограничения

* Задняя кромка должна быть замкнутой (`close_trailing_edge()` для остальных).
* Маршевый генератор O-сетки выворачивает ячейки, если первый шаг от стенки
  намного меньше шага по контуру (например, 33 точки на сторону при ds0 = 10⁻³).
  Для Эйлера это не мешает, для RANS понадобится отдельный (эллиптический или
  C-сеточный) генератор.
* Многосеточный ускоритель явной схемы (`mg_levels > 1`) неустойчив при M < 0,6 —
  экспериментальный, по умолчанию выключен. Основной путь — неявный решатель.
* В трансзвуке с сильными скачками (M ≥ 0,85) нужен умеренный `cfl_max` (~300):
  при больших шагах Ньютон может «застрять» на нефизичном положении скачков.
* При M < 0,3 нужно предобусловливание для малых чисел Маха (следующий этап).
* Сверхзвук (M > 1) пока не проверялся; граничное условие его поддерживает.
* Вязкий метод описывает срыв только до его начала; при развитом срыве и
  при Re ≲ 10⁵ возможна несходимость (точки помечаются как ненадёжные).
  По атласу UIUC до срыва не сходится 8 % точек (со сглаживанием контура),
  при Re = 10⁵ — 13 %: очень тонкие профили и ламинарный отрыв без
  присоединения у задней кромки. Измеренные координаты с шумом у передней
  кромки нужно сглаживать (`smooth_airfoil`, галочка в окне).
* Шарнирный момент: вязкий ch_δ простого руля — в пределах 5–20 % от опыта NACA,
  ch_α чувствителен к Ñкрит, влияние осевой компенсации занижено примерно на треть
  (см. «Проверено»). Открытая щель у носка руля учитывается эмпирической
  поправкой по продувкам NACA L-301 (`controls.gap_factors`, `apply_gap`): наклон
  cl(α) и приращение cl от руля уменьшаются (при 0,005–0,010c — на 6–9 %), ch
  пересчитывается при неизменной связи ch(cl). Поправка снята с одного профиля
  (NACA 0009, руль 0,30c, компенсация 0,20) — для других это оценка. Прямой
  расчёт щели (`controls.gapped`) — экспериментально, в окно не выведен.
* Cl систематически выше эксперимента на ≈ 0,04–0,05 (как у XFOIL).
* Механизация (`mviscous.py`): по умолчанию след переднего элемента не сливается
  с пограничным слоем закрылка (модель слияния есть, но на проверочных данных
  ухудшает точность); при δf ≈ 40° отрыв на закрылке переоценивается; верх закрылков
  по умолчанию турбулентный от носка. До Cl_max сходится и совпадает с опытом
  в пределах ≈ 0,05 по Cl; у Cl_max и при отрыве на закрылке (δf = 40° у
  GA(W)-1) Ньютон не сходится — такие точки помечаются. Одна точка с холодного
  старта — 1–6 мин (GA(W)-1 + Фаулер 20°: ≈ 2 мин; NACA 2412 + щелевой 20°: ≈ 5 мин —
  нужно продолжение по Re), по соседней точке поляры — 10–40 с. Поэтому поляру
  механизации лучше считать одним расчётом, а не точками по отдельности. Для генератора
  `highlift()` перекрытие закрылка лучше задавать положительным (0,01–0,03).

* RANS (`rans.py`): полностью турбулентный (переход не моделируется — при
  Re ≲ 10⁶ с ламинарными участками точнее вязкий метод); стационарный — за Cl_max,
  когда течение нестационарно, решение не устанавливается (точка помечается).
  Скорость (10.2026, NACA 0012, M 0,15, Re 6·10⁶, 14 тыс. ячеек, 4 ядра машины
  разработки под параллельной нагрузкой — на ПК пользователя проверить
  `benchmarks/verify_rans.py quick`):

  | вариант | α = 0° с нуля | α = 10° от 0° | Cl(10°) | Cd(10°) |
  |---|---|---|---|---|
  | до изменений (ограничитель везде) | 119 итер., 371 с | 130 итер., 538 с | 1,0848 | 0,01257 |
  | ограничитель только у задних кромок (по умолчанию) | 75 итер., 209 с | 83 итер., 256 с | 1,0894 | 0,01095 |
  | без ограничителя | 70 итер., 157 с | 84 итер., 193 с | 1,0838 | 0,01089 |
  | эталон NASA TMR (CFL3D, мелкая сетка) | | | 1,0909 | 0,01231 |

  Что ускорило: компиляция JAX один раз на решатель (раньше — на каждый угол, ~30 с) и
  постоянный кэш на диске (`~/.cache/aero2d/jax`, `AERO2D_JAX_CACHE`; новый процесс на той
  же сетке — секунды); свой GMRES вместо scipy; разложение ILU в 3 раза быстрее; главное —
  ограничитель Венкатакришнана только у задних кромок (`limiter_zone="te"`): во всём поле
  он срабатывал в 44 % ячеек, «дребезжал» и не давал невязке падать.
  **Открытый вопрос точности:** без ограничителя в поле Cd при α = 10° на этой сетке на
  11 % ниже эталона (давление 0,00483, трение 0,00612), с ограничителем везде — на 2 %
  выше; при 15° ограничитель везде завышал Cd на 11 %. Проверка на сетке мельче (27 тыс.
  ячеек) не закончена. Прежний режим — `limiter_zone="all"` (в окне: «Невязки» →
  «ограничитель: везде»). Fluent быстрее за счёт решателя по давлению с многосеточным
  методом; здесь — сжимаемый Ньютон–Крылов, при M ≈ 0,15 линейные системы плохо
  обусловлены (ILU при CFL ≥ 10⁴ даёт 30–90 итераций GMRES). Точное LU первого порядка
  в порядке вложенных сечений (`prec="lu"`) раскладывается за 2 с, но решение на угол
  тоже не быстрее.
  Узкое место — GMRES (умножения якобиана на вектор). Эти операции почти не
  распараллеливаются внутри процесса, поэтому ядра используются расчётом углов поляры
  в отдельных процессах (`workers`).
  Критерий сходимости — невязка ниже 10^−4,5 от невязки однородного потока при этом угле
  (одинаково для поляры и отдельной точки), силы стоят `hold` итераций; у тёплого старта
  ещё нужно падение в 100 раз от наибольшей невязки этого расчёта. Сетка механизации не
  зависит от угла (сгущение по следам при 0°, 6°, 12°) — поляра и отдельная точка
  считаются на одной сетке. Остаётся физическая неоднозначность за Cl_max (гистерезис).
  Сетка gmsh от запуска к запуску немного различается (±0,1 % ячеек) — Cl в 3-м знаке.
  При M < 0,1 считается при M = 0,1 (нет предобусловливания малых M).
* Нестационарный RANS (`solve_unsteady`, кнопка «Анимация по времени (GIF)»): BDF2,
  внутренние итерации Ньютона при CFL 300. Проверено только на грубых сетках (4–14 тыс.
  ячеек): работает, но SA на них даёт за Cl_max установившийся отрыв — срыва вихрей с
  установившегося решения может не быть; видимое развитие течения — при резком повороте
  потока или разгоне из покоя. Резкий старт однородного потока даёт сильные акустические
  волны (поэтому старт — плавный разгон за 0,5 хорды). Время на ЦП — минуты–десятки
  минут (шагов = время × шагов на хорду).
* Вязкий метод, неединственность: при переходе у задней кромки (NACA 4415, Re 10⁶,
  α ≈ 2–4°) есть несколько решений; теперь все точки считаются одним путём от α = 0
  через узлы 2° (`solve_path`) — поляра и отдельная точка совпадают, ветвь — как у XFOIL
  (α = 4°: Cl 0,945, XFOIL 0,951; холодный старт давал 0,804). Остаётся отличие Cl от
  XFOIL при α = 2°: 0,666 против 0,601 — режим крайне чувствителен (у XFOIL Cl растёт
  на 0,12 за 0,5°). Проверено: при Ue из XFOIL слой, переход и след aero2d повторяют
  XFOIL в пределах 0,5 %, при массовом дефекте XFOIL матрица влияния даёт его Ue
  (кроме узла задней кромки, +3 %) — расхождение в связанном решении у кромки.
  Защита от развала: откат к состоянию с наименьшей невязкой (рост в `rollback_factor`
  раз или NaN → CFL/10, 15 итераций первым порядком, до `max_rollbacks` раз), деление
  шага по α при развале на старте от соседнего угла, признак нестационарности по
  колебаниям Cl; карта невязки по ячейкам (`history["res_cell"]`, `"worst"`).
  Старт на грубой сетке (`coarse_start`, `coarse_options`, `transfer_state`): первый угол —
  на грубой сетке, затем все углы поляры сразу параллельно.
