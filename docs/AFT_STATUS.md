# Модель перехода SA-AFT в RANS — состояние работ (27.10.2026)

## Что сделано
- `aero2d/rans.py`: модель SA-AFT (Coder, NASA TMR, страница `aft_transition_3eqn`), выбор
  `turb_model="sa-aft"`. Калибровка `aft_version="2019b"` (по умолчанию) или `"2017b"`.
  Ещё 2 уравнения: ρñ (огибающая усиления волн Т–Ш) и ργ̃ (γ̃ = ln γ). Решатель обобщён на
  `nv` переменных (5 для SA, 7 для SA-AFT): `prim`/`cons`, поток Роу (скаляры),
  `visc_flux` (диффузия ñ, γ̃), стенка (∂/∂n = 0), внешняя граница (ñ = 0, γ̃ = 0),
  якобиан 7×7, `BlockILU0(k=nv)`, `solve`.
- Связь с SA: f_t2 = 1,2·(1 − e^min(γ̃,0)) в порождении и разрушении (`sa_source(..., ft2)`).
- ν̃/ν набегающего потока = 0,1 (`chi_inf_tr`), Ñкрит — из окна (`ncrit`).
- ∇d — точная ближайшая точка на отрезках стенки (`wall_direction`), для H_L.
- Устойчивость:
  - перенос ñ, γ̃ первого порядка;
  - за шаг Ньютона поячеечно ограничены изменения: ñ ≤ 1, γ̃ ≤ 1,5, χ ≤ 50 % (не меньше 1);
  - CFL ≤ `aft_cfl_max` = 300;
  - F_crit сглажена tanh (ширина 5 %).
- Точка перехода: признак ν̃/(κ u_τ y) > 0,5 у стенки (`forces()` → `elements[i]["gam"]`),
  `core._rans_xtr` → `Polar.xtr_u/xtr_l` и строка в примечаниях.
- Окно: пункт «SA-AFT (переход, Ñкрит из окна)». Проверка: `verify_rans.py aft` (E387,
  Re 2e5 / 3e5, α = 0…6°: LTPT, вязкий метод, SA). Тесты: `test_sa_aft_*`, `test_rans_xtr_*`.

## Результаты (NACA 0012, M 0,15, сетка ~10 тыс. ячеек, 2 ядра)
| случай | x_tr верх/низ | Cd | вязкий метод (как XFOIL) |
|---|---|---|---|
| Re 3e6, α 0, CFL до 1e4, 400 итер. | 0,36 / 0,53 | 0,0055 (колебания) | 0,51 / 0,51, Cd 0,00505 |
| то же + 250 итер. с CFL ≤ 200 | 0,53 / ~0,60 | 0,0042, ещё дрейфует | |
| Re 1e6, α 0 (2017b) | верх ламинарный до з.к. | ~0,0047, колебания Cl | 0,68, Cd 0,00538 |

## Нерешённое
1. **Нет установления.** Точка перехода медленно дрейфует или колеблется, и Cl ≠ 0 при α = 0
   (несимметрия). При малом CFL ход гладкий, но медленный: сотни итераций.
2. **Сетка.** По опыту Flow360 и OVERFLOW модели нужны сетки в сотни тысяч–миллионы
   узлов (2D). На грубой сетке переход получается позже, чем по XFOIL; в BL всего ~12 ячеек.
3. **Возможные шаги:**
   - сгладить F_onset (max/min → гладкие);
   - сделать γ̃ ≤ 0 жёстко;
   - добавить в предобусловливатель полный блок источника 3×3 (связь SA↔γ̃);
   - сделать при старте модели «рампу» Ñкрит;
   - проверить на пластине (Schubauer–Klebanoff, T3A) и NLF(1)-0416 (Ñкрит 7,2), уменьшать CFL при
     колебаниях Cl;
   - усреднять Cl/Cd по последним итерациям (уже есть `cl_mean`).

## Скрипты для отладки
`RansSolver(mesh, 0.15, 3e6); s.turb_model = "sa-aft"; s.solve(0.0, max_iter=400, verbose=2)` —
печатает невязки по уравнениям (7 столбцов: ρ, ρu, ρv, ρE, ρχ, ρñ, ργ̃).

## Обновление 07.11.2026
Проверка на **плоской пластине** (Re 5·10⁶ на длину, M 0,15, прямоугольная сетка 240×96,
y⁺ 0,5; нет носка, торможения и следа — только пограничный слой):
- полностью турбулентная SA: сходится за 79 итераций, Cf совпадает с 0,0576·Re_x^−0,2 до 1–3 %;
- ламинарный расчёт: с левым предобусловливанием GMRES «сходился» по ‖M⁻¹r‖ при истинной
  невязке ~0,2, CFL держался ~400, слой не развивался (Cd 0,00016 за 300 итераций). С правым —
  Блазиус до третьего знака по всей пластине за 90 итераций. Теперь при расчёте с переходом и
  ламинарном GMRES всегда с правым предобусловливанием;
- SA-AFT от ламинарного решения: H = 0,26·H_L + 2,4 ≈ 2,58–2,62 (Блазиус 2,59) — верно.
  Рост ñ (максимум по толщине слоя) против огибающей Дрелы (H 2,59, Re_θ0 244):

  | x | Re_x | ñ | N Дрелы |
  |---|---|---|---|
  | 0,05 | 2,5·10⁵ | 2,04 | 0,91 |
  | 0,2 | 10⁶ | 4,58 | 4,35 |
  | 0,4 | 2·10⁶ | 6,64 | 7,19 |
  | 0,6 | 3·10⁶ | 8,15 | 9,38 |
  | 0,8 | 4·10⁶ | 9,20 | 11,22 |

  Сетка вдвое мельче по x даёт то же (не дискретизация). Ñкрит 9 — у x ≈ 0,8 вместо 0,58:
  переход позже. Нужно сверить с эталоном TMR для AFT2019b на пластине (или найти ошибку в
  источнике ñ: F_growth, F_crit, Re_V0).
- Установления пока нет: невязки ñ, γ̃ стоят на ~0,2–0,5, при CFL > 300–1000 скачки ×100–800
  и откаты (и на пластине, и на NACA 0012). Источник неустойчивости — уравнения перехода.

## Обновление 08.11.2026 — переход на пластине сходится
Пластина Re 10⁷ (переход в середине, а не у выходной границы), старт от ламинарного решения,
настройки по умолчанию: **сошлось за 357 итераций**, Cd 0,00208. Cf: по Блазиусу до x ≈ 0,3,
переход x ≈ 0,33–0,40 (Re_x ≈ 3,5·10⁶; огибающая Дрелы при Ñкрит 9 — 2,8·10⁶), дальше
турбулентное трение. Что для этого понадобилось (всё — по умолчанию при `turb_model="sa-aft"`):
1. GMRES с правым предобусловливанием (ламинарный слой с левым не развивался).
2. γ̃ ≤ 0 при обновлении (`aft_gamma_cap`): у f_t2 излом в γ̃ = 0, шаг через него — скачок ×15.
3. Гладкое F_onset (softplus ширины 0,02 вместо max(·,0), `aft_onset_smooth`): источник γ̃
   ~10⁴·F_onset включался/выключался изломом — невязка на фронте перехода прыгала ×35.
4. Член Γ|∇γ̃|² в источнике γ̃ (`aft_grad_term`): уравнение для γ̃ = ln γ получается делением
   уравнения для γ на γ, (1/γ)∇·(Γ∇γ) = ∇·(Γ∇γ̃) + Γ|∇γ̃|² — раньше его не было.
5. Шаг уравнения ñ ×1000 (`aft_n_dt`): уравнение почти линейно по ñ, а при CFL 300 огибающая
   устанавливалась тысячи итераций.
6. Разгон шага ν̃ (`turb_boost`) — только без перехода: на ламинарном старте силы «спокойны»,
   разгон включался и шаг Ньютона для ñ, γ̃ упирался в ограничения.
7. Откат «к наименьшей невязке» и отмена шага — только при росте ×10⁶ и NaN (`aft_rollback`):
   пока формируется фронт перехода, невязка законно растёт на порядки, а откат возвращал
   ламинарное поле — переход не возникал.
8. Предел CFL 300 подстраивается: растёт ×1,2 за итерацию, когда невязка упала в 100 раз от
   наибольшей и силы установились (или упала в 300 раз), падает ÷4 при росте невязки вдвое.
   После того как фронт установился, CFL 10⁴–10⁵ — и сходимость за десятки итераций.

Осталось: ñ растёт медленнее огибающей Дрелы после Re_x ≈ 1,5·10⁶ (переход позже на ~25 %) —
сверить с эталоном TMR для AFT2019b; NACA 0012 (Re 3·10⁶, α 0) — в работе.
